# Showcase asset notes

These files are optimized public derivatives. The source files in `docs/screenshots/` and `docs/hackathon/` are unchanged. Sharp strips embedded metadata by default.

## Recorded product screenshots

The four product captures below come from `docs/screenshots/` and are already published in the repository README. They show historical recorded application state, not current public telemetry. All are WebP at quality 82, constrained to a maximum width of 1600 pixels without enlargement.

- `world-3d.webp`: the live infrastructure world, project islands, domain gateways, shared networks, and health states. Network membership is context rather than proof of an application dependency.
- `incident-timeline.webp`: recorded HTTP 502 evidence and subsequent reachable checks, with exact event times and separate recovery evidence.
- `agent-investigation.webp`: evidence-backed investigation of prism-web across deployment identity, telemetry, public routes, network membership, and logs.
- `agent-deployment.webp`: a concrete approval-bound deployment plan and recorded post-execution HTTPS 200 result.

## Genuine hackathon material

These assets come from `docs/hackathon/` and are already published in the README. The builders and badge images are genuine photographs; the winners image is the supplied event result graphic. All are WebP at quality 84, constrained to a maximum width of 1400 pixels without enlargement.

Caption source: the README Hackathon Award section records **Second Prize — Codex Community Hackathon Calicut**, held at **TinkerSpace on 19–20 September 2026**.

- `codex-hackathon-calicut-builders.webp`: Codex Community Hackathon Calicut builders working at TinkerSpace.
- `midhun-builder-badge.webp`: Midhun P M's builder badge for Codex Community Hackathon Calicut.
- `top-three-winners.webp`: the supplied top-three result graphic naming M. Mohith (Kea, first), Midhun P M (NightWatch, second), and Mohammed Shaad N (Loop, third).

## Synthetic scene artwork

- `islands-poster.webp`: synthetic concept artwork generated using the built-in imagegen tool, optimized to a maximum width of 1536 pixels at WebP quality 86. This is a cinematic illustration and fallback poster, not a product screenshot, telemetry snapshot, or depiction of current infrastructure.
- `nightwatch-social.jpg`: a 1200 × 630 centre-cropped social preview derived from the same synthetic poster, at JPEG quality 88.

Concise poster prompt: **Three floating infrastructure islands with silver server towers, charcoal surroundings, mint light and connections, no text.**

## Privacy inspection

Each selected product screenshot and hackathon asset was visually inspected at source resolution before public optimization. No visible passphrase, authentication token, API key, or credential was identified. The screenshots retain public domains, project names, resource identifiers, conversation text, and a plan identifier already visible in the README's source images. The event photos retain their original visible people and published event details.
